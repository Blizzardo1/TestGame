# Blizzeta Game Engine
## Also known as TestGame

[![Build](https://github.com/Blizzardo1/TestGame/actions/workflows/build.yml/badge.svg)](https://github.com/Blizzardo1/TestGame/actions/workflows/build.yml)

Originally, this engine had no name, until today, 6 May, 2025. Also, this was supposed to also be a game itself until I remembered that the logic should remain separate from the front-end application (game). The game will hook into the library and utilize most if not all components to deliver a final product.


---

## Libraries

This engine is fully backed by SDL2 and will eventually move into SDL3 territory. The current library used is [SharpSDL2](https://github.com/GeorchW/SharpSDL2) and needs some more loving. C# Game developers who love SDL2 as much as I do, help us out by completing the library with providing documentation as well as enhancing the product altogether!


## Packages

Currently, there are no releases available for download and must be built from source.

## Contribution

All contribution to the engine is welcome to help build a product that eventually will step into 3D territory. I'll be honest, its condition is very poor and written in about 500 man hours over the span of 5 years. While I've been experimenting with SDL2 in C#, I've built some test games like Snake to show the power of SDL2 with C# and it was a success in my book. I've also recreated Stones from Windows Entertainment Pack; however, the rules are not working, yet the stones can be placed. I still have to figure out a menu system for recreated games what utilize a Windows Menu System. I'm all for aesthetics to really bring memories from my childhood back to life. The Repo is available and can be found in my library. Bring it back to life please.
